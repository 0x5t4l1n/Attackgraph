Features

Everything you need for application security research

AttackGraph covers the complete workflow from discovery to reporting with no cloud dependencies and no data leaving your machine.

🕷

Active Web Crawler

Async crawler with scope enforcement, robots.txt compliance, rate limiting, form discovery, and configurable depth and concurrency.

📡

Burp Suite Import

Parse Burp Suite XML HTTP history exports. Requests are parsed, credential headers stripped, cookies redacted, and endpoints normalized.

📋

OpenAPI Import

Import OpenAPI 2.0, 3.0, and 3.1 specifications. Endpoints are extracted and cross-referenced against observed traffic.

🗺

Application Graph

Typed directed graph with host, endpoint, parameter, and auth nodes. Observed vs inferred relationships tracked with confidence scores.

🔍

Security Analysis

10 deterministic rules generate evidence-backed security hypotheses — never false confirmations. Findings include confidence, assumptions, and reproduction steps.

⚡

Attack Paths

Graph traversal engine discovers candidate attack paths from entry points to sensitive operations, scored by priority and confidence.

📝

Test Plans

Structured procedures with preconditions, step-by-step instructions, expected outcomes, evidence to capture, and cleanup steps.

📄

Security Reports

Export professional reports in Markdown, JSON, and HTML. All reports clearly distinguish confirmed findings from unvalidated hypotheses.

🤖

AI Assistant (Optional)

Optional OpenAI-compatible integration. Works with Ollama (local), OpenAI, Google Gemini, and OpenRouter. All core features work without AI.

Workflow

From discovery to report in 8 steps

AttackGraph guides you through a structured security assessment workflow with clear separation between observed facts and hypotheses.

1

Create a project and define scope

Configure the target URL, allowed hosts, allowed schemes, and excluded paths. All subsequent crawling and analysis respects these boundaries.

2

Collect application data

Run the active crawler on your authorized target, import Burp Suite HTTP history, or provide an OpenAPI specification. Use any combination.

3

Build the application graph automated

Click Build Graph to generate a typed directed graph from collected observations. Each node carries its evidence source and confidence score.

4

Run security analysis automated

10 deterministic rules analyze the graph and observations to generate candidate security findings. All findings start as unvalidated hypotheses.

5

Review findings and attack paths

Examine each finding with its description, reasoning, affected endpoints, confidence, and reproduction steps. Review candidate attack paths.

6

Execute approved test plans

Follow the generated test procedures on authorized targets. Update finding status as you validate, dismiss, or escalate each hypothesis.

7

Generate the security report

Export your assessment as Markdown, JSON, or HTML. Reports include executive summary, endpoint inventory, findings, attack paths, and a limitations disclaimer.

8

AI-assisted analysis optional

If an AI provider is configured, use the AI Assistant to summarize the application graph and get suggested analysis focus areas. Only redacted graph data is sent.

Installation

Get started on Linux

AttackGraph is available on Arch Linux via AUR, as a portable AppImage, as a .deb package, or buildable from source.

No Python, Rust, or Node.js required — the AUR package includes the bundled backend.

Using yay

yay -S attackgraph-bin

Using paru

paru -S attackgraph-bin

Manual build

git clone https://aur.archlinux.org/attackgraph-bin.git
cd attackgraph-bin
makepkg -si

Launch

# From app menu or terminal:
attackgraph

Portable — runs on any Linux x86_64 system without installation.

wget https://github.com/0x5t4l1n/Attackgraph/releases/download/v1.0.0/AttackGraph_1.0.0_amd64.AppImage
chmod +x AttackGraph_1.0.0_amd64.AppImage
./AttackGraph_1.0.0_amd64.AppImage

Requires webkit2gtk-4.1 and gtk3 (usually installed with any desktop environment).

wget https://github.com/0x5t4l1n/Attackgraph/releases/download/v1.0.0/AttackGraph_1.0.0_amd64.deb
sudo dpkg -i AttackGraph_1.0.0_amd64.deb
attackgraph

Requires: Python 3.11+, Node.js 18+, Rust 1.75+, webkit2gtk-4.1

git clone https://github.com/0x5t4l1n/Attackgraph.git
cd Attackgraph

# Python backend
python3 -m venv .venv && source .venv/bin/activate
pip install -e "backend[dev]"

# Desktop app (starts backend automatically)
cd frontend
npm install
cargo tauri dev

Responsible Use

Security and ethics

⚠️

AttackGraph is designed for authorized security testing only. Only use it against systems you own or have explicit written permission to test. Unauthorized testing is illegal and unethical.

🔒 Local-first by design

All project data is stored locally in a SQLite database at ~/.local/share/attackgraph/. No telemetry, no cloud sync, no external data transmission except optional AI API calls.

⚖️ Hypothesis-based findings

All findings are clearly labelled as unvalidated hypotheses until manually confirmed. AttackGraph never claims a vulnerability is confirmed from passive analysis alone.

🤖 Safe AI integration

AI features transmit only redacted graph summaries — never raw HTTP requests, credentials, session tokens, or full responses. AI output is clearly labelled as AI-generated.

🚫 Scope enforcement

The crawler enforces your configured scope at every step. Requests outside allowed hosts are never made. Robots.txt is respected by default.
