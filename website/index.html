// graph-first application security testing

AttackGraph is a local-first application security testing platform. Discover endpoints, model the attack surface as a directed graph, apply deterministic security rules, and export professional reports — all on your machine, with no cloud dependencies.

// capabilities

Everything you need for application security research

A complete workflow from discovery to reporting, with no cloud dependencies and no data leaving your machine.

🕷

Active Web Crawler

Async crawler with scope enforcement, robots.txt compliance, rate limiting, form discovery, and configurable depth, concurrency, and rate limit.

📡

Burp Suite Import

Parse Burp Suite XML HTTP history exports. Requests parsed, credential headers stripped, cookies redacted, endpoints normalized and deduplicated.

📋

OpenAPI Import

Import OpenAPI 2.0, 3.0, and 3.1 specifications. Endpoints extracted and cross-referenced against observed traffic.

🗺

Application Graph

Typed directed graph with host, endpoint, parameter, and auth nodes. Every edge tracked with evidence source and confidence score.

🔍

Security Analysis

10 deterministic rules generate evidence-backed security hypotheses. Findings include confidence %, assumptions, affected endpoints, and reproduction steps.

⚡

Attack Paths

Graph traversal discovers candidate paths from entry points to sensitive operations, scored by priority and confidence.

📝

Test Plans

Structured procedures with preconditions, step-by-step instructions, expected secure behavior, evidence requirements, and cleanup steps.

📄

Security Reports

Export in Markdown, JSON, and HTML. Reports clearly distinguish confirmed findings from unvalidated hypotheses. Includes limitations disclaimer.

🤖

AI Assistant (Optional)

Works with Ollama (local, no API key), OpenAI, Google Gemini, and OpenRouter. All core features work without AI — it is an enhancement only.

// workflow

From discovery to report in 8 steps

A structured assessment workflow with clear separation between observed facts and hypotheses at every step.

01

Create a project and define scope

Configure the target URL, allowed hosts, schemes, and excluded paths. All crawling and analysis respects these boundaries — nothing is collected outside scope.

02

Collect application data

Run the active crawler on your authorized target, import Burp Suite HTTP history, or provide an OpenAPI specification. Use any combination of the three.

03

Build the application graph automated

Click Build Graph. A typed directed graph is generated from collected observations. Each node carries its evidence source, type, and confidence score.

04

Run security analysis automated

10 deterministic rules analyze the graph and observations. All findings start as unvalidated hypotheses — no false confirmations.

05

Review findings and attack paths

Examine each finding with its reasoning, affected endpoints, assumptions, confidence, and reproduction steps. Review candidate attack paths with priority scores.

06

Execute approved test plans

Follow generated test procedures on authorized targets. Update finding status as you validate, dismiss, or escalate each hypothesis.

07

Generate the security report

Export as Markdown, JSON, or HTML. Report includes executive summary, endpoint inventory, findings, attack paths, test plans, and limitations disclaimer.

08

AI-assisted analysis optional

If an AI provider is configured, the AI assistant summarizes the application graph. Only redacted graph summaries are transmitted — never raw requests or credentials.

// installation

Get started on Linux

Available on Arch Linux via AUR, portable AppImage, .deb package, or build from source.

No Python, Rust, or Node.js required. The AUR package bundles everything.

yay

yay -S attackgraph-bin

paru

paru -S attackgraph-bin

manual

git clone https://aur.archlinux.org/attackgraph-bin.git
cd attackgraph-bin && makepkg -si

launch

attackgraph

Portable — runs on any Linux x86_64 without installation.

wget https://github.com/0x5t4l1n/Attackgraph/releases/download/v1.0.0/AttackGraph_1.0.0_amd64.AppImage
chmod +x AttackGraph_1.0.0_amd64.AppImage
./AttackGraph_1.0.0_amd64.AppImage
wget https://github.com/0x5t4l1n/Attackgraph/releases/download/v1.0.0/AttackGraph_1.0.0_amd64.deb
sudo dpkg -i AttackGraph_1.0.0_amd64.deb
attackgraph

Requires Python 3.11+, Node.js 18+, Rust 1.75+, webkit2gtk-4.1

git clone https://github.com/0x5t4l1n/Attackgraph.git
cd Attackgraph
python3 -m venv .venv && source .venv/bin/activate
pip install -e "backend[dev]"
cd frontend && npm install
cargo tauri dev

// responsible use

Security and ethics

⚠

AttackGraph is designed for authorized security testing only. Only use it against systems you own or have explicit written permission to test. Unauthorized testing is illegal and unethical regardless of the tools used.

🔒

Local-first by design

All data stored at ~/.local/share/attackgraph/. No telemetry, no cloud sync, no external transmission except optional AI API calls.

⚖

Hypothesis-based findings

All findings are unvalidated hypotheses until manually confirmed. AttackGraph never claims a vulnerability is confirmed from passive analysis alone.

🤖

Safe AI integration

AI calls transmit only redacted graph summaries — never raw HTTP requests, credentials, session tokens, or full responses.

🚫

Scope enforcement

Crawler enforces your configured scope at every step. Requests outside allowed hosts are never made. Robots.txt respected by default.
